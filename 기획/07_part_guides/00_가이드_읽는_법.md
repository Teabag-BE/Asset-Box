# 00. 파트별 가이드를 읽는 법

> 모든 파트 가이드는 동일한 7개 섹션으로 구성됩니다.

| 섹션 | 무엇을 답하는가 |
|---|---|
| 1. 책임 한 줄 | "내가 무엇을 만드는가?" |
| 2. 패키지 / 파일 소유권 | "어떤 파일이 내 것인가? 남이 손대면 안 되는 곳은?" |
| 3. 외부 컨트랙트 (내가 제공) | "다른 파트가 나를 부를 때 어떤 메서드/API?" |
| 4. 의존하는 컨트랙트 (내가 호출) | "내가 다른 파트를 부를 때 어떤 메서드/API?" |
| 5. 단계별 작업 가이드 (M0 → M3) | "마일스톤별로 뭘 한다?" |
| 6. 인수 기준 (AC) + 테스트 시나리오 | "완료의 기준은?" |
| 7. 충돌 방지 / 자주 묻는 함정 | "이렇게 하면 옆 파트가 깨진다" |

> **충돌 방지의 핵심**: 본 가이드의 "외부 컨트랙트" 와 "의존 컨트랙트" 가 정확히 맞물려야 합니다. 파트장은 자기 가이드의 3번이 다른 파트의 4번과 일치하는지 매주 확인.
