## 원칙

- **5/26은 코드 작성일이 아니다.** API/ERD 확정, 역할별 책임 확인, 로컬 빌드 기준 확인만 한다.
- **5/27부터 코드 착수**한다.
- 각 파트는 자기 패키지 안에서 먼저 세로로 얇게 동작시키고, 5/30부터 도메인 간 연결을 시작한다.
- M1에서는 멋진 기능보다 **컴파일, API 응답, 핵심 플로우 연결**이 우선이다.
- Admin 강제 삭제, DM 강제 열람, DownloadLog/통계, Kakao OAuth, WebSocket 실시간화는 M1 범위가 아니다.
