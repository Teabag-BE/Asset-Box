## 파트별 산출물 책임 (간단 버전 — 자세한 건 `07_part_guides/` 참고)

### 1) User

- 엔드포인트: `/api/users/`**, `/api/admin/users/`**
- 엔티티: `User`, `Role` (enum)
- 공통: `JwtProvider`, `JwtAuthenticationFilter`, `CurrentUser` (이미 `common.security`에 있음, 유지보수만)
- 외부 노출 컨트랙트: `Long userId`, `String nickname`, `String avatarUrl`

### 2) File-A (저장 담당)

- 엔드포인트: 업로드는 Post-A의 multipart 안에 들어옴 → **서비스 호출만 책임**
- 엔티티: `AssetFile`
- 핵심 클래스: `FileStorageService` (인터페이스), `LocalFileStorageService` (현재 구현)
- 외부 노출 컨트랙트: `AssetFile saveAndAttach(postId, file, isThumbnail)`

### 3) File-B (다운로드/로그/통계)

- 엔드포인트: `/api/posts/{postId}/files/{fileId}` (다운로드, Post-A와 협의된 위치), `/api/admin/download-logs/`**
- 엔티티: `DownloadLog`
- 비동기: `@Async` 로 로그 적재
- 외부 노출 컨트랙트: `Resource download(postId, fileId, requester)`, `Page<DownloadStats>` 조회

### 4) Post-A (게시글 본체) + 게시판 + 댓글

- 엔드포인트: `/api/posts/`**, `/api/admin/posts/**`
- 엔티티: `Post`, `PostLike`
- 협업: File-A·File-B의 서비스를 호출(직접 엔티티 X), Comment의 카운트가 필요하면 Comment 서비스 호출

### 5) Post-B (Request 게시판)

- 엔드포인트: `/api/requests/**`, `/api/requests/{id}/comments/**`(댓글은 Comment 파트 협업)
- 엔티티: `RequestPost`, `RequestComment`, `RequestStatus`(enum)
- 상태 전이 규칙, TA 배정, 완료시 Post 연결 (Post-A 협업)
- 상태 변경 시 DM 알림 → **DM 파트의 service 호출 (REST X)**

### 6) Comment + Category + Search

- 엔드포인트: `/api/posts/{postId}/comments/`**, `/api/categories/`**, `/api/posts?...search params`
- 엔티티: `Comment`, `Category`, `Tag`
- 검색은 Post-A의 Repository에 쿼리 메서드를 추가하기보다 **자기 service에서 Spec/JPQL 작성** (오너십 분리)

### 7) DM (Message)

- 엔드포인트: `/api/messages/`**, `/api/admin/messages/`**
- WebSocket: `/ws` 엔드포인트, `WebSocketConfig` (이미 있음)
- 외부 노출 컨트랙트: `MessageService.send(fromUserId, toUserId, content)` — 다른 파트(Request)가 알림으로 호출

### 8) Infra (PM 보조)

- build.gradle, Dockerfile, docker-compose, GitHub Actions, prometheus.yml
- `common.config.*`, CORS, GlobalExceptionHandler 유지
- **DDL 게이트키퍼**: 엔티티 신규/변경 PR은 Infra 리뷰 필수
- 시드 데이터(`AdminBootstrapRunner`, `CategorySeeder`) 관리

## 단독 파트가 막힐 때

단독 파트(Comment+Cat+Search, DM)는 짝이 없어서 막히면 외롭습니다. 규칙:

1. **막히면 30분 이상 혼자 끙끙대지 말 것** — 슬랙 `#assetbox-help` 채널에 즉시 질문
2. PM이 매일 단독 파트 4명에게 1:1 핑(5분) — 진척 + 막힌 점 확인
3. PR이 24시간 동안 리뷰 0개면 PM이 직접 리뷰어 지정
