# 02. 기획 변경 로그

> 기획 변경의 단일 진실 소스. ERD, API, 일정, 파트 가이드가 바뀌기 전에 먼저 이 문서에 결정 내용을 기록한다.

## 사용 규칙

1. 변경 결정이 나오면 이 문서에 새 항목을 추가한다.
2. `영향 문서` 체크리스트를 채운 뒤 해당 문서를 수정한다.
3. `잔재 검색` 명령을 실행해 옛 표현이 남았는지 확인한다.
4. PR 본문에 변경 로그 항목 제목을 붙인다.

## 2026-06-04 — File 도메인 명칭/필드 최신화

### 결정

- `AssetFile` 명칭은 사용하지 않고 `File` 도메인으로 통일한다.
- 테이블명은 `files`로 한다.
- `original_name`, `saved_name`, `saved_url`을 모두 둔다.
- `stored_path`, `resource_type`, `resource_id`는 사용하지 않는다.
- `domain_type`, `domain_id`, `uploaded_by`, `upload_order`, `content_type`, `file_type`을 사용한다.
- `file_type`은 목적 분류로 사용한다: `MODEL`, `REFERENCE`, `THUMBNAIL`, `PROFILE`.
- 게시글 썸네일, 유저 프로필 이미지, 요청 참고 썸네일은 File FK가 아니라 각 도메인의 URL 컬럼으로 보존한다.
