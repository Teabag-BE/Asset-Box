# 03. 문서 동기화 체크리스트

> 기획 변경 시 어느 문서를 같이 봐야 하는지 정리한 체크리스트. 작은 변경이어도 이 문서를 먼저 확인한다.

## 기본 절차

1. `00_overview/02_기획_변경_로그.md`에 변경 결정을 기록한다.
2. 아래 변경 유형별 체크리스트에서 영향 문서를 고른다.
3. 문서를 수정한다.
4. 잔재 검색을 실행한다.
5. PR 본문에 변경 로그 항목과 잔재 검색 결과를 적는다.

- [ ] PR 본문에 변경 로그 항목과 검증 명령을 적었다.
- [ ] 기획 변경과 무관한 코드/문서를 섞지 않았다.
