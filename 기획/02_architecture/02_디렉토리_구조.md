## 리소스 / 설정 (`assetbox/src/main/resources/`)

```
resources/
├─ application.yml             # 공통
├─ application-dev.yml         # 개발 (H2, ddl-auto: create-drop)
├─ application-prod.yml        # 운영 (MySQL, ddl-auto: validate)
├─ data.sql                    # 시드 (선택)
└─ logback-spring.xml
```

> **DDL 자동 생성**: 현재 dev는 `create-drop`. 배포 직전(M2 후반)에 prod 프로파일을 `validate` 로 잠그고, 이후 스키마 변경은 마이그레이션 스크립트로만. (Flyway는 v1.1)

## 절대 어기지 말 것 (디렉토리 관련)

1. **도메인 패키지 안에서 다른 도메인 패키지의 `domain/` / `repository/` 직접 import 금지.**
   - 허용: `import com.assetbox.message.service.MessageService` (서비스 호출)
   - 금지: `import com.assetbox.message.domain.Message` (엔티티 빌려쓰기) — Post-A/B 외 도메인
   - 예외: `User` 는 거의 모든 도메인이 참조 — `User` 엔티티 import 는 허용. 단 응답 DTO에는 노출하지 말 것 (`UserResponse` 로 매핑).
2. **`common/` 에 도메인 로직 절대 금지.** 공용 인프라(보안/예외/응답)만.
3. **`controller` 에서 `repository` 직접 호출 금지.** 항상 `service` 경유.
4. **새 도메인을 만들고 싶을 땐 PM과 상의.** 도메인 폭주는 머지 충돌의 어머니.
