# 02. 코딩 컨벤션

> 비유: **같은 폰트로 쓴 8장의 편지.** 글씨체가 다르면 한 사람이 쓴 책처럼 안 읽힌다. 컨벤션은 8명의 글씨체를 맞춰주는 자.

## 언어 정책

- **에러 메시지(예외 포함), 주석, 커밋 메시지, PR**: 한국어
- **변수 / 메서드** : 영어 (Lower camelCase / Upper camelCase)
- **클래스 / 패키지 : Pascal case, 패키지는 소문자**
- **DB : Snake case**
- **에러 코드 (`USER_NOT_FOUND`)**: 영어 UPPER_SNAKE
- **로그 메시지**: 한국어 OK (다만 검색 가능하게 일관)
- 테스트 코드 : BDD 방식, 쉽게말하면 친절히 풀어서 설명하기. 모르면 정수님 블로그로 (++[https://velog.io/@wjdtn747/행동-주도-개발-BDD-givenwhenthen-Nested-DisplayName](https://velog.io/@wjdtn747/행동-주도-개발-BDD-givenwhenthen-Nested-DisplayName))++  
e.g.  
상위 : Describe_Repositort의 save메서드는  
중위 : Context_올바른_데이터가_주어진_경우  
하위: It_저장_성공()

## 클래스 / 메서드 네이밍


| 종류           | 컨벤션                        | 예                                                     |
| ------------ | -------------------------- | ----------------------------------------------------- |
| Entity       | 단수 명사                      | `Post`, `Message`, `File`                             |
| Repository   | `<Entity>Repository`       | `PostRepository`                                      |
| Service      | `<Domain>Service`          | `PostService`, `RequestStatusService`                 |
| Controller   | `<Domain>Controller`       | `PostController`, `AdminPostController`               |
| Request DTO  | `<Action><Entity>Request`  | `PostCreateRequest`, `PostUpdateRequest`              |
| Response DTO | `<Entity>Response`         | `PostResponse`, `UserResponse`, `PostSummaryResponse` |
| Enum         | UpperCamel, 값은 UPPER_SNAKE | `RequestStatus.IN_PROGRESS`                           |


서비스 메서드 동사:

- 조회: `get / find / list / search / requireExists`
- 변경: `create / update / softDelete / changeStatus / assign`
- 위임: `attach / send / log`

## 응답 / 예외

### 응답

모든 컨트롤러 반환 타입은 `ApiResponse<T>` 또는 `ResponseEntity<ApiResponse<T>>`. 직접 `T` 노출 금지.

```java
return ApiResponse.ok(postService.get(postId, currentUserId));
```

### 예외

- 비즈니스 예외는 `BusinessException` 정적 팩토리:
  - `throw BusinessException.notFound("POST_NOT_FOUND", "게시글을 찾을 수 없습니다.");`
  - `throw BusinessException.badRequest("FILE_TOO_LARGE", "파일은 20MB 이하여야 합니다.");`
  - `throw BusinessException.unauthorized(...)`, `forbidden(...)`
- 자바 표준 예외 (`IllegalArgumentException` 등) 던지지 말 것 — `GlobalExceptionHandler` 매핑이 불명확해진다.(?)

## JPA 사용 규칙


| 항목           | 룰                                                    |
| ------------ | ---------------------------------------------------- |
| 엔티티 기본 생성자   | `@NoArgsConstructor(access = AccessLevel.PROTECTED)` |
| 생성자          | `@Builder` + 필수 필드만                                  |
| 양방향 관계       | 지양. 단방향 + ID 참조 우선                                   |
| Fetch        | 기본 LAZY (이미 강제됨). EAGER 사용 시 PR에서 사유 명시              |
| 트랜잭션 경계      | 서비스 메서드. 읽기 전용은 `@Transactional(readOnly = true)`    |
| save 후 즉시 사용 | 같은 트랜잭션 안에서 영속 컨텍스트로 OK. 다른 트랜잭션이면 명시적 flush         |
| N+1 회피       | 목록 응답은 fetch join 또는 EntityGraph                     |

## DTO 매핑

- 엔티티 → DTO는 정적 팩토리 메서드: `PostResponse.from(post, currentUserLikeStatus)`
- 또는 매퍼 클래스 (`PostMapper`) — 본 프로젝트는 정적 팩토리 우선
- MapStruct 도입은 v1.1

## Lombok 사용


| 권장                                       | 비권장                              |
| ---------------------------------------- | -------------------------------- |
| `@Getter` 엔티티에서                          | `@Data` (Setter 까지 열림)           |
| `@Builder` 빌더 패턴                         | `@AllArgsConstructor` 단독         |
| `@NoArgsConstructor(access = PROTECTED)` | `@NoArgsConstructor` 기본 (public) |
| `@RequiredArgsConstructor` 서비스/컴포넌트      | 필드 직접 `@Autowired`               |
| `@Slf4j` 로깅                              | `System.out.println`             |

## 로깅

- `log.info` — 비즈니스 이벤트 (요청 작성, 상태 전이)
- `log.warn` — 예측된 실패 (검증 실패는 굳이 로깅 X)
- `log.error` — 진짜 예외 (스택트레이스 포함)
- `log.debug` — 개발 디버깅용. prod 레벨 INFO

PII (이메일/주민번호 등) 로깅 금지. user.id만.

## Git 커밋 메시지 — `[TYPE] 한국어 한 줄`

PR 제목·개별 커밋 메시지 모두 동일 형식.

```
[FEAT] 게시글 작성 + 파일 첨부 multipart 처리
[FIX] DM 안 읽은 수 갱신 안 되는 버그
[CHORE] CI에 coverage 단계 추가
[REFACTOR] PostService 좋아요 토글 분리
[TEST] Post 작성 인수 기준 테스트 추가
[DOCS] API 검색 쿼리 파라미터 추가
[WIP] post create skeleton  ← 작업 중 임시. 머지 전 정리.
```

타입(대괄호 안, 대문자): **FEAT / FIX / CHORE / DOCS / REFACTOR / TEST / PERF / WIP**

상세 규칙은 `[01_Git_브랜치_PR_규칙.md](./01_Git_브랜치_PR_규칙.md)` 참고.
