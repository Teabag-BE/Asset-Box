# AssetBox · 기획 문서 (PM 패키지)

> 이 폴더는 8명이 한 달 동안 같은 그림을 보고 일하기 위한 **단일 진실 소스 (Single Source of Truth)** 입니다.
> 코드보다 이 폴더가 먼저 바뀌고, 그 다음 코드가 따라옵니다.

---

## 비유로 먼저

- `**기획/` = 건축 도면 묶음.** 도면이 흐릿하면 벽 두 개가 어긋난 채 만나서 머지 충돌이 터집니다.
- **각 도메인 = 건물의 한 층.** 같은 콘센트 규격(= API 컨트랙트)만 지키면 층마다 다른 인테리어를 해도 전기는 통합니다.
- **PM = 건축가.** 도면을 그리고, 충돌을 미리 잡고, 일정의 진척을 추적합니다.
- **각 파트장 = 시공 책임자.** 자기 층은 자기가 책임지고, 도면을 바꿀 일이 생기면 다른 층과 협의 후 도면부터 수정합니다.

## 핵심 원칙 5가지 (TL;DR)

1. **컨트랙트가 먼저, 구현은 나중.** API 명세(`04_api/`)와 ERD(`03_erd/`)를 먼저 합의한 다음에 구현합니다. 컨트랙트는 PR이 아닌 *기획 변경 회의*로만 바꿉니다.
2. **남의 도메인 엔티티는 직접 import 하지 않습니다.** 필요하면 ID(Long) 만 들고, 조회가 필요하면 그 도메인의 service를 통합니다. (모듈러 모놀리스 원칙)
3. **DB 마이그레이션 책임은 한 명.** 같은 컬럼을 두 명이 동시에 만들면 100% 깨집니다. (Infra가 게이트키퍼)
4. **모든 응답은 `ApiResponse<T>` 포맷.** 프론트가 일관되게 다룰 수 있도록.
5. **테스트는 사치가 아니라 충돌 방지 장치.** 각 도메인 핵심 시나리오 1~2개는 머지 전 반드시 작성.
